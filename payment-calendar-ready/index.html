Нужна ещё одна настройка

Чтобы данные синхронизировались между устройствами, приложению нужна бесплатная база данных Firebase. Заполните файл js/firebase-config.js данными вашего проекта — подробная пошаговая инструкция есть в README.txt, раздел «Настройка Firebase».

После этого обновите страницу.
